# Resume Screening and Candidate Ranking System

## Future Interns - Machine Learning Internship (Task 3)

## Project Overview

This project is a Resume Screening and Candidate Ranking System developed using Natural Language Processing (NLP) and Machine Learning.

The system automatically analyzes resumes, compares them with a given job description, calculates similarity scores, ranks candidates, and identifies missing skills.

It simulates a real-world Applicant Tracking System (ATS) used by recruiters.

---

## Features

- Resume Text Preprocessing
- Text Cleaning using NLTK
- TF-IDF Feature Extraction
- Job Description Matching
- Cosine Similarity Calculation
- Resume Ranking
- Skill Gap Analysis
- Candidate Ranking Visualization

## Machine Learning Workflow

1. Load Resume Dataset
2. Data Cleaning
3. Text Preprocessing
4. Resume Text Cleaning
5. TF-IDF Vectorization
6. Create Job Description
7. Convert Job Description into Vector
8. Calculate Cosine Similarity
9. Rank Candidates
10. Detect Missing Skills
11. Visualize Top Candidates
